# テンきっぷ (Ten Kippu)

切符の4桁の数字を全部使い、足す・引く・掛ける・割る（と括弧）で 10 を作る「テンパズル」を、
60 秒のタイムアタックにした計算パズル。何問解けたかを競う。

- HTML5 / CSS3 / Vanilla JavaScript（ライブラリ・バックエンドなし）
- 自己ベストは `localStorage` に保存。それ以外は何も送信・保存しない
- ホスティング：Cloudflare Workers（静的配信）

## 遊び方

- **数字 → 記号 → 数字** の順にタップすると、2 つの数字が計算結果にまとまる（数字 → 数字 → 記号 でも可）
- 3 回まとめて残った 1 つが **10** なら正解。自動で次の切符へ
- 10 にならなかったときは最後の計算だけ自動で戻る。それ以前は「戻す」で 1 手ずつ戻せる
- **パス**は −5 秒。解けない切符に時間を使うより、次へ進んだほうが得なことが多い
- 制限時間 60 秒。結果画面では各切符の正解・パス・時間切れと、解答例が見られる
- キーボード：`1`〜`4` で左から数字を選択、`+ - * /` で記号、`Backspace` で戻す、`P` でパス、`Enter` でスタート

## 出題のしくみ

`solver.js` が 4 つの数字の全順列 × 記号 × 括弧の付け方を分数演算で全探索し、
10 になる式をすべて列挙する。出題は以下のルール。

- **必ず解ける切符しか出さない**（0000 や 1111 のような解なしは出ない）
- **途中計算が分数になる解しかない切符は出さない**（1158 → `8÷(1−1÷5)` のような有名な難問は除外）
- 難易度は「整数だけで解ける式の数（`intCount`）」で決め、正解数に応じて段階的に上げる
  （`script.js` の `tierFor`）。解き筋が多い切符ほど人にも易しい傾向がある

| 正解数 | intCount の範囲 | 目安 |
|---|---|---|
| 0〜2 問 | 41 以上 | 足し引きだけで解ける |
| 3〜5 問 | 12〜40 | 掛け算・割り算が 1 つ入る |
| 6〜8 問 | 5〜20 | 括弧が要ることが多い |
| 9 問〜 | 1〜8 | 解き筋が数本しかない |

同じ組み合わせは 1 回のプレイ中に重複して出さない。

## 調整ポイント

`script.js` 冒頭の定数と `tierFor` を編集する。

```js
const TIME_LIMIT = 60;    // 制限時間（秒）
const PASS_PENALTY = 5;   // パスで減る秒数
```

## 難易度分析（任意）

`solver.js` は `globalThis.TenSolver` に公開しているので、Node からも使える。
全 715 通りの組み合わせの解の数を見たいときは、例えば以下。

```js
require("./solver.js");
const r = globalThis.TenSolver.solve([1, 1, 5, 8]);
console.log(r.count, r.intCount, r.best); // 1 0 "8÷(1−1÷5)"
```
