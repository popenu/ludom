# 消えるまるばつ (Kieru Marubatsu)

まるもばつも、盤に置けるのは3つまで。4つ目を置くと、その人のいちばん古い印が消える三目並べ。
引き分けで終わりにくく、「次にどれが消えるか」まで読む対戦になる。

- HTML5 / CSS3 / Vanilla JavaScript（SVG。ライブラリなし）
- CPU への最高連勝数を `localStorage` に保存。それ以外は何も送信しない
- ホスティング：Cloudflare Workers（静的配信）

## ルール

- ○が先攻。交互に空いているマスへ置く
- 4つ目を置いた瞬間に、自分のいちばん古い印が消える。そのあと、残った3つが縦・横・斜めに並んでいれば勝ち
- 手番の人が3つ持っているとき、次に消える印はうすく点滅する
- 60手（`MOVE_LIMIT`）で決着がつかなければ引き分け

## モード

- **CPUと対戦**：先攻・後攻を選ぶ。CPU への連勝数の最高記録を残す
- **ふたりで対戦**：1台の端末で交代して置く
- PC はテンキー配置の数字キー（7 8 9 / 4 5 6 / 1 2 3）でも置ける

## CPU（`script.js` の `cpuChoose`）

4手先まで読む negamax（αβ枝刈り、`CPU_DEPTH`）。同点の手からランダムに選ぶ。
読み切れない局面は、次に消える印を除いた「2つ並んで残り1マスが空いている列」の数で評価する。
