# おつり名人 (Otsuri)

小銭が大きらいな「薄井さいふ」になって、1日10軒の買い物をするパズル風ゲーム。
お会計のたびに財布から硬貨・紙幣を選んで払い、お店は最少枚数でお釣りを返す。
**会計後の財布の小銭（硬貨）を、できるだけ少なくする**のが目的。財布は次のお店へ持ち越し。

- HTML5 / CSS3 / Vanilla JavaScript（ライブラリ・バックエンドなし）
- 自己ベスト（合計点）と「導入ムービーを見たか」を `localStorage` に保存。それ以外は何も送信しない
- 効果音は Web Audio で合成（音声ファイルなし）
- ホスティング：Cloudflare Workers（静的配信）

## 遊び方

- 財布のお金をタップするとトレイ（出すお金）へ。トレイのお金はタップで財布に戻る
- 「支払う」で会計。足りなければ「あと○円足りません」で出し直し（減点なし）
- 不要なお金を出しすぎると、店員が「こちらはお返ししますね」と返してくれる（減点なし）
- 会計ごとに行列のイライラゲージ（15秒）。ゲージが切れると急かされて**お札だけで自動払い**（0点）
- 自販機は 1円・5円玉と 5千円札・1万円札が使えない。お釣りも硬貨（500・100・50・10円）だけ
- PC は 1〜9 キーで 1円〜1万円を出す、Esc で全部戻す、Enter で支払う／次へ

例：財布に 500円玉1、100円玉2、10円玉3、1円玉2、千円札2 があり、会計が 1,027円
→ 千円札1＋10円玉3＋1円玉2（1,032円）を出すと、お釣りは 5円玉1枚。

## 導入ムービー

初回の「はじめる」直後に、約21秒の紙芝居風ムービー（SVG＋CSS アニメーション＋テロップ）が流れる。
小銭でパンパンの財布 → 1円玉を探して行列に睨まれる → 財布がはじける → 「小銭は、持たない。」と誓う
→ 1万円札＋527円で 3,527円を払い、お釣りがお札だけになる決めシーン → タイトル。

- 「スキップ」ボタン、画面タップで次のシーン、Esc / Enter でスキップ
- 一度見る（またはスキップする）と次回からは自動で飛ばす。スタート画面の「導入をもう一度見る」で再生
- シーンは `script.js` の `SCENES`（表示時間・HTML・テロップ）で編集する

## 採点の計算方法

### お店のお釣り
支払額 S、会計 P のとき、お釣り S − P を**最少枚数**（大きい金種から順に取る貪欲法）で返す。
日本の金種はこの貪欲法で最少枚数になる。

### 店の返却（出しすぎ）
出したお金の中に「お釣りにも含まれる金種」があれば、その1枚を返却して計算し直す（なくなるまで繰り返す）。
お釣りの最少分解に金種 d が含まれるとき、C − d の最少分解は d を1枚減らしたものになる（全額で確認済み）ので、
返却しても会計後の財布は変わらない。見た目を自然にするための処理。

### 最善の小銭枚数（DP）
支払額 S を決めるとお釣りは決まるので、

```
会計後の硬貨 = 今の硬貨 − 出した硬貨の枚数 + お釣り(S − P) の硬貨の枚数
```

となる。そこで「財布の中身でちょうど S を作るとき、出せる硬貨の最大枚数」を
有界ナップサック DP（金種ごとに 0〜持っている枚数）で全ての S について求め、
P 以上の全ての S で上の式を評価して最小値を「最善」とする（同点なら支払額の小さいほう）。
払い方も DP の表から復元して、精算画面で「最善の出し方」として見せる。

この計算は総当たり（全ての払い方を列挙）と照合して一致を確認している。
`script.js` は node から `require` すると計算部分（`optimize` / `settle` / `greedy` など）だけを返す。

### 1軒あたりの得点（100点満点 × 10軒 = 1000点満点）

```
得点 = max(0, 100 − 25 × (あなたの硬貨枚数 − 最善の硬貨枚数) − 遅れ減点)
遅れ減点 = 20 × (経過秒 − 6) ÷ (15 − 6)   … 6秒までは0、15秒直前で最大20（四捨五入）
```

- 最善と同じ枚数なら「完璧」
- ゲージ切れ（15秒）はお札だけで自動払い（足りなければ大きいお金から順に出す）、0点

各会計の最善は「その時点の財布で」計算する（次の店まで見越した最善ではない）。

### 出題の調整
- 初期財布：1万円札1、5千円札0〜1、千円札2〜4、500円玉0〜1、100円玉1〜4、50円玉0〜2、10円玉2〜6、5円玉0〜2、1円玉2〜7
- お店は12種類から10軒をランダムに選ぶ。会計金額はお店ごとの値段帯から決め、
  「お札だけで払ったとき」と「最善」の差が2枚以上になる金額を最大25回まで探して優先する

## ファイル構成

```
index.html   ... HTML構造・UI（スタート／プレイ／結果の3画面と導入ムービー）
style.css    ... 商店街のお買い物（赤白の日よけ・レジ表示・カルトン・革の財布）とムービーの演出
script.js    ... 最善の計算（DP）・お店と出題・財布とトレイ・お釣りのアニメーション・導入ムービー・効果音
README.md    ... このファイル
```

硬貨・紙幣は色と大きさの雰囲気だけを本物に寄せた簡略デザイン（肖像や実際の図柄は描かない）。
