# HRタイプ診断 (HR Type)

16の質問に答えると、人事としての持ち味を16タイプから診断する。
4軸それぞれ2択で、4文字コード（例：`SADM`）が付く。人事コミュニティの入口で
「私は〇〇型です」と名乗れるようにする、共通言語づくりの遊び。

- HTML5 / CSS3 / Vanilla JavaScript（ライブラリ・バックエンドなし）
- 回答はどこにも送信・保存しない
- **Ludomのトップには載せない。`noindex` 付き**。URLを知っている人だけが開ける

## 軸とコード

| 位置 | 左 | 右 |
|---|---|---|
| 1文字目 | ヒト派 `P` | シクミ派 `S` |
| 2文字目 | 攻め `A` | 守り `G` |
| 3文字目 | 直感 `I` | データ `D` |
| 4文字目 | 現場派 `F` | 経営派 `M` |

各軸4問、配点 `2,1,1,1` の合計5点。奇数なので同点は出ない。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 画面 |
| `style.css` | スタイル |
| `script.js` | 軸・設問・採点・画面遷移 |
| `types.js` | 16タイプの本文（名前、一言、解説、持ち味、裏側、燃える議題、自己紹介テンプレ、組むと強い相手） |
| `img/XXXX.jpg` | タイプごとのキャラ画像（640px）。`XXXX` はコード4文字 |
| `img-src/` | 元画像（2048px）。gitignore 済みでコミットしない |

## キャラ画像の差し替え

1. 元画像を `img-src/XXXX.jpeg` に置く
2. 以下で 640px の表示用を作り直す

```bash
cd hr-type && for f in img-src/*.jpeg; do n=$(basename "$f" .jpeg); sips -Z 640 -s format jpeg -s formatOptions 82 "$f" --out "img/$n.jpg" >/dev/null; done
```

## シェア

結果URLは `hr-type/#SADM` のようにコードがハッシュに入る。
開くと診断なしでそのタイプの結果が表示され、「自分も診断する」に誘導する。

## ローカルでの動作確認

```bash
python3 -m http.server 8080
```

`http://localhost:8080/hr-type/` を開く。
