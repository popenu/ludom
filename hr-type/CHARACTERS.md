# HRタイプ診断 キャラ画像プロンプト

やさしい絵本風の和風イラスト（2頭身、まん丸の顔、淡彩）で16体を作るためのGemini用プロンプト。
生成時は毎回、完成済みの採用ハンター（PAIF）を添付し、末尾の「添付と同じ線・淡さ・顔・頭身で」を効かせる。

- 髪は全員「黒の総髪を後ろで小さく結ぶ」で固定。髷・丸髷・ひげは使わない（性別に読まれるため）
- 見分けは着物の柄・目の形・表情・かぶり物で付ける
- 着物の基調色：採用系オレンジ／組織系グリーン／制度系ブルー／労務系パープル
- 背景は真っ白一色で出す。サイトの背景が白いのでJPEGのまま使える。ファイル名はコード4文字（例 `PAIF.jpeg`）

```
やさしい絵本の挿絵のような和風イラスト。細く均一な濃い茶色の線画に、淡い水彩の色を薄く置く。背景は完全な真っ白一色。影はほとんどなく、平坦でやわらかい塗り。2頭身のデフォルメで、頭を大きく、体は小さく。手足は短く、手は丸い握りこぶし。全身、正面やや斜め。文字は入れない。正方形の構図で人物を中央に大きく。顔：輪郭はあごのないまん丸。目は顔の下半分に置き、大きくて黒目がはっきり、左右を離す。目にハイライトを2つ。眉は細く薄く、目から離す。頬にふんわり赤み。口角の上がった小さな口。親しみやすく、幼く見えるかわいらしい顔立ち。性別も年齢も分からない中性的な顔で、髪は黒く、総髪を後ろで小さく結ぶ。髷や丸髷、ひげはなし。16体すべて同じ髪型。

【キャラクター】天文方。グリーンの着物に袖をたすきで留めている。江戸時代の木製の象限儀（四角い天板の付いた木の台の上に、四分円の目盛り板と、その上を回る細長い照準棒が載った観測器具。添付の写真の器具）の横に立ち、背伸びをして照準棒に片目を近づけ、斜め上の空を覗いている。もう片方の手には、星を線で結んだ星図（折れ線グラフのように見える）を持っていてもよい。
【柄と表情】着物は霰（あられ）の点柄。丸眼鏡、口をきゅっと結ぶ。顔の作りと髪型は他の15体と同じで、着物の柄・表情・かぶり物だけを変える。
【基調色】グリーンを着物のメインカラーにする。
【役割のイメージ】人事の「ピープルアナリスト」。人の話を、経営の言葉にする。

添付の画像（採用ハンター）と同じ線、同じ色の淡さ、同じ顔の作り、同じ頭身で描く。16体シリーズの1体として、他の15体と揃えられるシンプルな描き方。
```
