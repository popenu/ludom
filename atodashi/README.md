# あと出しじゃんけん (Atodashi)

相手の手と「勝って」「負けて」「あいこ」の指示を見て、正しい手をすばやく出す反射脳トレ。
30秒で何問正解できるかを競う。「負けて」と言われると、つい勝つ手を出してしまうのがポイント。

- HTML5 / CSS3 / Vanilla JavaScript（ライブラリ・バックエンドなし）
- 自己ベスト（正解数）を `localStorage` に保存。それ以外は何も送信しない
- ホスティング：Cloudflare Workers（静的配信）

## 遊び方

- スタート後、3・2・1 のカウントで開始。制限時間は30秒（`DURATION`）
- 相手の手（グー・チョキ・パー）と指示を見て、下の3つのボタンから正しい手を押す
- 正解するとすぐ次の問題。間違えると0.6秒（`MISS_LOCK`）押せなくなり、連続正解が途切れる
- PC は 1・2・3 キー（または A・S・D）でも出せる。Enter でスタート
- タッチは `pointerdown` で反応させて、click の遅延をなくしている

## 指示の出かた（`ordersAt`）

| 経過時間 | 出る指示 |
|---|---|
| 0〜8秒 | 勝って だけ |
| 8〜18秒 | 勝って・負けて（負けて多め） |
| 18〜30秒 | 勝って・負けて・あいこ |

直前と同じ問題（相手の手と指示が両方同じ）は続けて出さない。

## 結果

正解数・正答率・最大連続・平均反応時間（正解までの秒数）と、指示ごとの正解数を表示する。

| 正解数 | 称号 |
|---|---|
| 32〜 | 後出しの神 |
| 26〜 | 反射の達人 |
| 20〜 | なかなかの手 |
| 12〜 | ふつうの人 |
| それ未満 | つい勝っちゃう人 |
