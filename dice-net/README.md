# サイコロ展開図 (Dice Net)

立方体の展開図を見て「反対側の面は？」「組み立てるとどれ？」に答える空間パズル。全10問。
展開図は11種類すべてを回転・反転してランダムに出題するので、問題は尽きない。

- HTML5 / CSS3 / Vanilla JavaScript（ライブラリ・バックエンドなし）
- 自己ベスト（正解数）を `localStorage` に保存。それ以外は何も送信しない
- ホスティング：Cloudflare Workers（静的配信）

## 遊び方

- 第1〜3問は「反対側の面は？」。展開図の太枠の面と向かい合う面を4択から選ぶ
- 第4〜6問はどちらか、第7問以降は「組み立てるとどれ？」。見取り図4つから正しいものを選ぶ
- 見取り図のニセモノは「鏡写し」と「向かい合う面が同時に見えている」の2種類
- 制限時間はなし。正解数と、かかった時間を記録する。PC は 1〜4 キーでも答えられる

## しくみ（`script.js`）

- **展開図の列挙**：1マスから育てて6マスのヘキソミノ（自由型35種）を作り、`foldsToCube` で立方体に折れる11種だけ残す
- **折りたたみ**：根のマスを底面（法線 −Z）に置き、隣のマスへ移るたびに枠（法線 N・東 E・北 T）を90°回す。
  東へ移るなら `N'=E, E'=−N`、北へ移るなら `N'=T, T'=−N`。6マスの法線がすべて異なれば立方体になる
- **反対側の面**：法線を反転した面
- **見取り図**：上・手前・右の3面。`右 = 上 × 手前`（外積）で右手系にすると正しい見取り図になり、
  手前と右を入れ替えると鏡写しになる
- 面は色と記号で区別する。記号は回転しても同じ形（丸・四角・ひし形・十字・輪・バツ）なので向きは問わない


## ローカルでの動作確認

```bash
python3 -m http.server 8080
```

`http://localhost:8080/dice-net/` を開く。
