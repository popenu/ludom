# 正直村と嘘つき村 (Honest Village)

正直者はいつも本当のことを言い、嘘つきはいつも嘘をつく。村人の発言から全員の正体を当てる論理パズル。
全10問。問題はプログラムが生成し、**答えが一つに決まるものだけ**を出題する。

- HTML5 / CSS3 / Vanilla JavaScript（ライブラリ・バックエンドなし）
- 自己ベスト（正解数）を `localStorage` に保存。それ以外は何も送信しない
- ホスティング：Cloudflare Workers（静的配信）

## 遊び方

- 村人をタップすると ？ → 正直者 → 嘘つき と切り替わる（PC は 1〜5 キー）
- 全員決めたら「答え合わせ」。正解でも不正解でも、各発言が本当か嘘かの解説が出る
- 第1〜3問は3人、第4〜6問は4人、第7〜10問は5人

## 発言の種類（`script.js` の `TYPES`）

| 種類 | 文 |
|---|---|
| honest / liar | 「Aは正直者だ」「Aは嘘つきだ」 |
| same / diff | 「AとBは同じ種類だ」「違う種類だ」 |
| bothLiar / bothHonest | 「AもBも嘘つきだ」「AもBも正直者だ」 |
| oneHonest | 「AかBの少なくとも一人は正直者だ」 |
| countLiars | 「この中に嘘つきはちょうどk人いる」 |

## 生成のしくみ

1. 正体をランダムに決める（全員同じは除外）
2. 各村人に、自分の正体と矛盾しない発言をランダムに割り当てる（自分自身については言わない）
3. 全 2^n 通りを総当たりして、矛盾しない正体の組が **ちょうど1つ** のものだけ採用

注意点：「正直者だ／嘘つきだ／同じ／違う」だけの問題は、全員の正体を反転させても矛盾が出ないため
答えが必ず2通りになる。そこで「AもBも」「少なくとも一人」「人数」のような反転に弱い発言を
必ず1つは含める（`ASYM`）。3人で「人数」の発言を使うと答えが「全員嘘つき」に偏るので、
3人のうちは「AもBも」「少なくとも一人」型を使う。
