# 一筆書き (Hitofude)

図形を指でなぞって、全部の線を一度ずつ通る一筆書きパズル。全10問のタイムアタック。
図形はプログラムが生成し、**必ず一筆で書ける形だけ**を出題する。

- HTML5 / CSS3 / Vanilla JavaScript（Canvas・Pointer Events。ライブラリなし）
- 自己ベスト（10問のクリアタイム）を `localStorage` に保存。それ以外は何も送信しない
- ホスティング：Cloudflare Workers（静的配信）

## 遊び方

- 点に指を置いて、離さずに線をなぞる。隣の点に届くと線が朱色になる
- 全部の線が朱色になったらクリア。次の図形へ
- 行き止まり、または指を離すとミス。同じ図形で2回ミスするとヒント（始点候補が光る）
- 「ヒント」ボタンでいつでも表示できる。「別の図形」は +10秒で作り直し

## 図形の生成（`script.js` の `generate`）

- 格子点（第1〜3問 3×3、第4〜6問 4×3、第7〜10問 4×4）の隣どうしを線でつなぐ。
  斜め線は1マスに1本だけにして、線どうしが交差しないようにする
- ランダムに線を選び、**線のある点が連結**で、**奇数本の線が集まる点が0個か2個**のものだけ採用
  （オイラー路が存在する条件）
- 奇数点が2個なら、その一方から始めてもう一方で終わる。0個ならどこから始めても始点で終わる

## なぞりの判定

- `pointerdown` で最も近い点（半径30px以内）をつかむ
- `pointermove` で、現在の点と未通過の線でつながった点に入ったら、その線を通過扱いにする
- 全線通過でクリア。未通過の線が残っているのに進める線がなければ「行き止まり」


`http://localhost:8080/hitofude/` を開く。
