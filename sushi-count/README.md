# 回転寿司カウント (Sushi Count)

回転寿司のレーンを流れる皿をよく見て、止まったら質問に答える観察・記憶ゲーム。
「サーモンは何皿通った？」「3番目に通ったのは？」「いちばん多かったのは？」「全部でいくら？」。
問が進むほど皿の数・種類・速さが増える。3回まちがえたら閉店。

- HTML5 / CSS3 / Vanilla JavaScript（ライブラリ・バックエンドなし）
- 自己ベストは `localStorage` に保存。それ以外は何も送信しない
- ホスティング：Cloudflare Workers（静的配信）

## 遊び方

- 皿が右から左へ流れる。全部通り過ぎると質問が出る
- 4択から **8秒以内** に選ぶ（PC は 1〜4 キーでも可）。時間切れも不正解
- 湯呑み3つ＝ライフ3。0になったら閉店、正解数がスコア
- 第1〜3問は「〇〇は何皿？」と先に出るので、その皿だけ数えればよい。第4問からは止まってから質問が出る

## 難易度のしくみ（`script.js` の `paramsFor`）

| 問 | 皿の数 | 種類 | 速さ（レーン幅/秒） | 出題 |
|---|---|---|---|---|
| 1〜3 | 6〜8 | 3 | 0.36〜0.43 | 何皿（先に出題） |
| 4〜6 | 9〜11 | 4 | 0.46〜0.53 | 何皿・何番目 |
| 7〜9 | 12〜14 | 5 | 0.57〜0.64 | ＋いちばん多いのは |
| 10〜 | 14 | 6 | 0.67〜0.80 | ＋全部でいくら（皿の色で値段） |

皿の色と値段：白 100円（たまご・かっぱ巻き）、青 150円（サーモン・えび）、赤 200円（まぐろ）、金 300円（いくら）。
「いちばん多かったのは」で同数になったときは「何皿」に切り替えて出題する。
