# いろまぜ (Iromaze)

お題の色を、赤・黄・青・白・黒の絵の具で作る調色ゲーム。全5問。
絵の具を押すたびにパレット（10マス）に1マスずつ乗り、「まぜる」で一発勝負。お題との色の差で1問100点、500点満点で称号が決まる。

- HTML5 / CSS3 / Vanilla JavaScript（ライブラリ・バックエンドなし）
- 自己ベスト（合計点の最大）を `localStorage` に保存。それ以外は何も送信しない
- ホスティング：Cloudflare Workers（静的配信）

## 遊び方

- 絵の具ボタンで1マスずつ乗せる。パレットのマスをタップすると取り除ける。「ぜんぶ戻す」で空にする
- 混ぜられるのは1問1回。途中経過は見えない
- 比率が同じなら量は問わない（赤1・黄1 と 赤2・黄2 は同じ色）
- PC は R/Y/B/W/K（または 1〜5）で絵の具、Backspace で1マス戻す、Enter／スペースでまぜる・次へ

## お題

裏でランダムなレシピ（各色1〜4マス、合計10マス以内）を作り、その混色結果をお題にする。必ずぴったり作れる。
名前は、いちばん近い伝統色（`script.js` の `NAMED`）から付ける。1ゲーム内で同じ名前は出さない。

| 問 | レシピに使う絵の具 |
|---|---|
| 1 | 赤・黄・青のうち2色 |
| 2 | 赤・黄・青のうち2色＋白 |
| 3 | 赤・黄・青 |
| 4 | 赤・黄・青＋白か黒 |
| 5 | 赤・黄・青のうち2〜3色＋白＋黒 |

## 混色の計算（`color.js`）

RGB の平均だと青＋黄が灰色になってしまうので、絵の具の混色理論で計算している。

- 各絵の具に 380〜730nm（10nm刻み）の反射率曲線を持たせる
- Kubelka-Munk 理論で、波長ごとに K/S を着色力（`t`）で重み付けして平均し、反射率に戻す
- CIE 1931 等色関数の近似式（Wyman 2013）で XYZ → sRGB に変換。反射率1.0の白が無彩色になるよう正規化

絵の具の色味や効きの強さは `PIGMENTS` の `f`（反射率）と `t`（着色力）で調整する。

## 採点

お題とできた色の差を CIEDE2000（ΔE）で測り、`100 × exp(-(ΔE/16)^1.4)` を点数にする（ΔE 0.5未満は100点）。
1マス違い（ΔE 5前後）で約80点、でたらめに混ぜると0〜20点程度。

| 合計 | 称号 |
|---|---|
| 470以上 | 色の神 |
| 420以上 | 名人 |
| 340以上 | 職人 |
| 240以上 | 見習い |
| それ未満 | 絵の具まみれ |
