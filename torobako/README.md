# トロ箱わたり (Torobako Crossing)

魚市場の猫になって、水に浮かぶ発泡スチロールのトロ箱を渡るパズル。
箱は一度踏むとヒビが入り、二度踏むと割れて水に落ちる。
**全部の箱を一度ずつ踏む**と出口ののれんが開き、奥の魚にたどり着けば面クリア。

- HTML5 / CSS3 / Vanilla JavaScript（ライブラリ・バックエンドなし）
- 到達した面を `localStorage` に保存（「続きから」用）。それ以外は何も送信しない
- ホスティング：Cloudflare Workers（静的配信）

## 遊び方

- **スワイプ**／**となりの箱をタップ**／画面下の**矢印ボタン**で1マス移動（PC は矢印キー・WASD、R でやり直し）
- ヒビの入った箱をもう一度踏むと割れて落ちる → 同じ面をやり直し
- 進める箱がなくなると「行き止まり」→ やり直し
- 全部の箱を踏むと、のれんが上がって出口に入れる

## 面のしくみ

`script.js` の `genPath()` が、内側グリッドの外周から始まり外周で終わる**長さ k の自己回避路**を
ランダムな深さ優先探索で作る。その道の上に箱を並べ、始点の隣の外枠に岸（入口）、終点の隣の外枠に
のれん（出口）を置く。道そのものが解答なので、必ず渡り切れる面しか出ない。

面ごとの大きさと箱の数は `LEVELS`（第1面 3×3 に 7 箱 〜 第10面 7×6 に 36 箱）。
それ以降は最大サイズで箱の数を揺らして出題する。

## ファイル構成

```
index.html   ... HTML構造・UI（猫の SVG もここ）
style.css    ... 夜明けの魚市場デザイン（水面・箱・のれん・猫のアニメーション）
script.js    ... 面の生成・移動判定・ヒビ/落下/クリアの進行
README.md    ... このファイル
```

## ローカルでの動作確認

```bash
python3 -m http.server 8080
```

`http://localhost:8080/torobako/` を開く。
