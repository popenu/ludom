# だるまさんがころんだ (Darumasan)

夕暮れの校庭で遊ぶ、だるまさんがころんだ。
長押ししている間だけ前に進み、離すと少し滑って止まる。鬼は「だるまさんがころんだ」を毎回ちがう緩急で唱え、言い終わると振り返る。
振り返ったときに動いていたらアウト。鬼にタッチするとステージクリアで、全5ステージの合計タイムを競う。

- HTML5 / CSS3 / Vanilla JavaScript（ライブラリ・バックエンドなし）
- 描画は Canvas（360×480 の論理座標）。鬼とプレイヤーは図形で描いている
- 効果音は Web Audio で生成。右上のボタンでミュート（`localStorage` に保存）
- 自己ベスト（クリア数→合計タイムの順で比較）を `localStorage` に保存。それ以外は何も送信しない
- ホスティング：Cloudflare Workers（静的配信）

## 遊び方

- 画面（Canvas）か下の大きなボタンを長押しで前進。PC はスペースキーを押している間前進
- 鬼が「だ」を言った瞬間に振り返り始める。振り返りアニメーション（`TURN_MS` = 190ms）の間は猶予で、終わった時点で動いていたらアウト
- 離しても慣性で約0.17秒・0.25m 滑る（`DECEL`）。滑っている間も「動いている」扱いなので、早めに離すのがコツ
- 鬼が見ている間（ステージごとに1.4〜3.4秒）は動いてはいけない。後ろを向き直したらまた唱え始める
- 長押しでの文字選択・長押しメニュー・スクロールは `user-select:none` / `touch-action:none` / `contextmenu` 抑止で防いでいる

## 鬼の唱え方（パターン）

毎回、基本の速さを ±20% ほどランダムに変えたうえで、次のどれかのパターンで唱える。

| パターン | 内容 |
|---|---|
| normal | ふつう（1文字ごとに少し揺らぐ） |
| rush | 途中から急に早口 |
| hold | 「ころん……」と溜めてから「だ！」 |
| slowstart | ゆっくり始まって後半が速い |
| stutter | 途中で間を空けて、そこから一気に |
| burst | 最初から最後まで超早口 |

ほかに、ステージ2以降は確率でフェイント（振り返りかけて戻る。判定なし）が入る。

## 障害物

ステージ2以降、鬼が唱えている間に横からタイヤ（ステージ4からはドッジボールも）が転がってくる。

- 出現の約0.75秒前（`OBS_WARN_MS`）に、通るレーンの影と画面端の「！」で予告する
- レーンはプレイヤーの1.0〜3.2m先。奥行き ±0.45m（`OBS_DEPTH`）以内で横位置が重なるとアウト
- 鬼が振り返っても止まらない。レーンの上で止まると避けられないので、一気に抜けるか手前で待つ
- ボールはタイヤより約1.6倍速く、跳ねながら転がる

| ステージ | 唱えるたびの出現率 | 最大個数 | 横切る秒数 | 種類 |
|---|---|---|---|---|
| 1 | なし | - | - | - |
| 2 | 55% | 1 | 2.4〜3.0秒 | タイヤ |
| 3 | 70% | 1 | 2.0〜2.7秒 | タイヤ |
| 4 | 80% | 2 | 1.8〜2.5秒 | タイヤ・ボール |
| 5 | 90% | 2 | 1.5〜2.3秒 | タイヤ・ボール |

## ステージ

| ステージ | 距離 | 基本間隔 | 出るパターン | フェイント |
|---|---|---|---|---|
| 1 | 12m | 330ms | normal | なし |
| 2 | 15m | 300ms | normal / hold / rush | 12% |
| 3 | 18m | 270ms | ＋slowstart / stutter | 20% |
| 4 | 21m | 245ms | ＋burst | 25% |
| 5 | 24m | 225ms | すべて（意地悪寄り） | 32% |

## 称号

| 結果 | 称号 |
|---|---|
| 全クリア・85秒未満 | 気配ゼロの忍 |
| 全クリア・110秒未満 | だるま名人 |
| 全クリア | 校庭の主 |
| 4ステージ | あと一歩の勇者 |
| 3ステージ | 休み時間の常連 |
| 2ステージ | つられ屋さん |
| 1ステージ | 元気な一年生 |
| 0ステージ | 正直者 |

速度・猶予・ステージ・称号のしきい値は `script.js` 冒頭の定数（`MAX_SPEED` / `DECEL` / `TURN_MS` / `STAGES` / `RANKS`）で調整する。
