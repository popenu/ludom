# 線路つなぎ (Rail Link)

バラバラになった線路のタイルをタップで回転させ、車庫からすべての駅へ線路をつなぐパズル。
全タイルがつながれば開通。路線（ステージ）が進むほど盤面が大きくなる。

- HTML5 / CSS3 / Vanilla JavaScript（ライブラリ・バックエンドなし）
- サイズ別の自己ベストタイムを `localStorage` に保存。それ以外は何も送信しない
- ホスティング：Cloudflare Workers（静的配信）

## 遊び方

- タイルを**タップで右に90°**回転（PC は右クリックで左回り）
- 車庫（朱色の二重丸）とつながった線路は黒くなり、つながった駅には色がつく
- 全タイルがつながると開通。時間と手数が出て、サイズ別の自己ベストを更新する
- 「別の盤面」で同じサイズの盤面を作り直せる

## 盤面のしくみ

`script.js` の `generate()` が、盤面全体を覆う**ランダムな全域木**（ループなし・ひとつながり）を
Prim 法風の手順で作り、各マスの接続をタイルの形にしてからランダムに回転させて出題する。

- 木なので解は必ず存在し、「全マスが車庫とつながる」＝「元の木に戻った」になる
- 端点（接続が1本）のマスが駅、中央のマスが車庫
- 最初から開通している盤面は出さない

盤面サイズは `sizeFor(stage)`：第1〜2路線 4×4、以降2路線ごとに1マス広がり、最大 8×8。

## ファイル構成

```
index.html   ... HTML構造・UI
style.css    ... 紙の路線図デザイン（地図記号の線路）
script.js    ... 盤面生成・接続判定・タイマー・自己ベスト
README.md    ... このファイル
```

## ローカルでの動作確認

```bash
python3 -m http.server 8080
```

`http://localhost:8080/rail-link/` を開く。
