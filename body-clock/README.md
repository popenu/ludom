# 体内時計 (Body Clock)

3秒・10秒・30秒の3ラウンド。スタートすると数字と秒針が動くが、最初の数秒で消える。
目標だと思ったところでタップして止め、3ラウンドのズレの合計で称号が決まる。

- HTML5 / CSS3 / Vanilla JavaScript（ライブラリ・バックエンドなし）
- 自己ベスト（ズレ合計の最小）を `localStorage` に保存。それ以外は何も送信しない
- ホスティング：Cloudflare Workers（静的配信）

## 遊び方

- 時計をタップでスタート。3秒ラウンドは1秒、10秒は2秒、30秒は3秒だけ数字が見える（`VISIBLE`）
- 消えたら心の中で数え、目標だと思ったところでもう一度タップ
- スタートから0.3秒以内のタップは二度押しとみなして無視する（`MIN_STOP`）
- PC はスペース／Enter でも操作できる

## 称号（ズレの合計）

| 合計 | 称号 |
|---|---|
| 0.5秒未満 | 原子時計 |
| 1.0秒未満 | 人間時計 |
| 2.0秒未満 | 駅の時計 |
| 4.0秒未満 | 腹時計 |
| 8.0秒未満 | 砂時計 |
| それ以上 | 日時計 |

ラウンドの秒数と称号のしきい値は `script.js` 冒頭の `ROUNDS` / `VISIBLE` / `RANKS` で調整する。

## ローカルでの動作確認

```bash
python3 -m http.server 8080
```

`http://localhost:8080/body-clock/` を開く。
