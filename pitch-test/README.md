# 絶対音感テスト (Pitch Test)

音が鳴ったら鍵盤で答える、全10問の音感テスト。正解数で称号が決まる。
音は Web Audio API でブラウザが合成するので、音源ファイルは不要。

- HTML5 / CSS3 / Vanilla JavaScript（ライブラリ・バックエンドなし）
- モード別の自己ベストを `localStorage` に保存。それ以外は何も送信しない
- ホスティング：Cloudflare Workers（静的配信）

## 遊び方

- **絶対音感モード**：いきなり1音が鳴る。鍵盤（ド〜シ、黒鍵含む12音）で答える
- **相対音感モード**：先に「ド」が鳴り、続けて出題音が鳴る。差で当てる
- 第1〜5問は白鍵だけ、第6〜10問は黒鍵も出題
- 「もう一度聞く」で何度でも聞き直せる（PC は R キー）
- 不正解のときは、自分が選んだ音 → 正解の音 の順に鳴る

## 称号（正解数）

| 正解 | 称号 |
|---|---|
| 10 | 調律師 |
| 8〜9 | 絶対音感の持ち主 |
| 6〜7 | 音楽室の主 |
| 4〜5 | カラオケの主役 |
| 2〜3 | 鼻歌名人 |
| 0〜1 | 音の冒険家 |

## 音の合成（`script.js` の `playNote`）

C4（261.63Hz）を基準に平均律で周波数を求め、基音＋倍音（2〜5倍、振幅 1 / 0.45 / 0.22 / 0.1 / 0.05）の
サイン波を重ねて、指数関数で減衰させたピアノ風の音。AudioContext はスタートボタンのタップで作る
（iOS はユーザー操作なしに音を出せないため）。

## ファイル構成

```
index.html   ... HTML構造・UI（鍵盤は script.js が生成）
style.css    ... 夜の音楽室デザイン

README.md    ... このファイル
```

## ローカルでの動作確認

```bash
python3 -m http.server 8080
```

`http://localhost:8080/pitch-test/` を開く。
