# ほんとに何割引？ (Waribiki)

「30%引きのあとにクーポンで50%OFF」は80%引きではなく65%引き。
こういう勘違いしやすい割引計算を、スーパーのチラシ・値札シール風の見た目で10問出題するクイズ。
誤答の選択肢は「よくある勘違い」から作ってあり、最後に**あなたが引っかかった勘違いのクセ**を診断する。

- HTML5 / CSS3 / Vanilla JavaScript（ライブラリ・バックエンドなし）
- 自己ベスト（合計点の最大）を `localStorage` に保存。それ以外は何も送信しない
- 効果音は Web Audio で合成（音声ファイルなし）
- ホスティング：Cloudflare Workers（静的配信）

## 遊び方

- 値札とシールを見て答えを選ぶ。計算問題は4択、「どっちがお得」は2択（ポイント還元の問題だけ「どちらも同じ」を含む3択）
- 1問15秒（レベル3の問題は20秒）。タイマーが切れると不正解
- 答えると正解と式（例：`1,000 × 0.7 × 0.5 = 350円`）、ひとこと解説が出る。「次へ」で進む
- PC は 1〜4 キーで選択、Enter で次へ（スタート・結果画面では Enter で開始）

## 問題（6タイプ、毎回ランダム生成）

| タイプ | 例 | 答え方 |
|---|---|---|
| 半額シール | 半額シールの上からさらに2割引 → いくら？ | 4択 |
| 重ね割引 | 定価2,000円を30%引き、さらに50%OFFクーポン → いくら？／合計何%引き？ | 4択 |
| どっちがお得 | 「◯円引き」vs「◯%OFF」、「2点目半額」vs「全品◯割引」、「3点目無料」vs「全品◯割引」、「30%引き」vs「20%引き＋10%ポイント還元」 | 2〜3択 |
| 税込・税抜 | 税抜980円を2割引すると税込（10%／食品8%）いくら？ 1円未満切り捨て | 4択 |
| まとめ買い | 「3個パック◯円」vs「単品◯円の2割引」で3個 | 2択 |
| 逆算 | 4割引で1,200円だった商品の定価は？ | 4択 |

### 並びと難易度
- 10問 = 6タイプを1回ずつ ＋ ランダムに4問（同じタイプは最大2回、連続はしない）
- タイプごとの基本難度（半額 < 重ね < どっちがお得 < 税 < まとめ買い < 逆算）に揺らぎを足して並べる
- 1〜3問目はレベル1、4〜7問目はレベル2、8〜10問目はレベル3（逆算・まとめ買いは最低レベル2）。
  レベルが上がると金額が半端になり、割引率の組み合わせが増え、軽減税率・3点目無料・合計%を問う問題などが出る
- 「どっちがお得」は同じセットの中でなるべく別の種類を出す

### 数値の作り方
割合は10%単位。定価は100円単位（半額シールは20円単位、まとめ買いの単品は10円単位、税抜価格は ◯80円・◯98円・◯50円 なども）で、
割引後の金額が必ず整数になる組み合わせだけを作る。税込計算で端数が出るときだけ「1円未満は切り捨て」と問題文に書く。
「どっちがお得」は引き分けにならない組み合わせだけを出す（ポイント還元の「同じ」は常に誤答）。

## 勘違いの種類（誤答の選択肢に紐付け）

| キー | 診断名 | 誤答の例 |
|---|---|---|
| add | 割引を足し算しがち | 30%引き＋50%OFF → 80%引き、半額＋2割引 → 7割引 |
| remain | 値引き額と支払額を取り違えがち | 支払額の代わりに値引き額、逆算で 1,200÷0.4 |
| taxForget | 税込にし忘れがち | 割引後の税抜価格のまま |
| taxOrder | 割引と税をまとめて足し引きしがち | 2割引で税10% → 1割引 |
| taxRate | 軽減税率をうっかりしがち | 8%と10%の取り違え |
| reverseMul | 逆算で掛け算に戻しがち | 4割引で1,200円 → 1,200×1.4 |
| pointSame | ポイント還元を値引きと同一視しがち | 「30%引き」と「20%引き＋10%還元」は同じ |
| secondHalf | 「2点目半額」に弱い | 2点目半額 = 半額と思って割引と比べ間違える |
| fixedVsRate | 定額と定率の比較が苦手 | 「500円引き」と「10%OFF」の比較 |
| bulkTrap | まとめ買い＝お得と思い込みがち | パックのほうが高いのにパックを選ぶ |
| calc | 計算ミスしがち | 上のどれにも当てはまらない近い値（片方の割引だけ、正解±刻み） |

結果画面では、間違えた問題の勘違いを数えて最も多いものを「あなたのクセ」として表示する（同数なら calc 以外を優先）。
時間切れは勘違いに数えない。間違えた問題は一覧で、あなたの答え・正解・式を表示する。

## 採点

```
正解 = 100点 ＋ 速さボーナス round(50 × 残り時間 ÷ 制限時間)
不正解・時間切れ = 0点
```

10問で最大1500点。

## ファイル構成

```
index.html   ... HTML構造・UI（スタート／プレイ／結果の3画面）
style.css    ... スーパーのチラシ（黄色い網点の紙、白い値札、赤・黄・青の丸シール、点線のクーポン、手書き風POP）
script.js    ... 問題の生成（6タイプ）・選択肢と勘違いの紐付け・タイマー・採点・診断・効果音
README.md    ... このファイル
```

`script.js` は node から `require` すると出題部分（`generateSet` / `gen` / `MISTAKES` / `scoreFor`）だけを返す。
出題を数千セット生成して、正解が選択肢にちょうど1つあること、選択肢が重複しないこと、金額が整数で妥当な範囲にあること、
「どっちがお得」に引き分けがないこと、正解を問題文から独立に計算し直して一致することを確認している。

## ローカルでの動作確認

```bash
python3 -m http.server 8080
```
