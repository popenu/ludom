# お得はどっち？ (Otoku Docchi)

「500g450円の肉と300g310円の肉、どっちが安い？」というスーパーでよくある悩みを、10問のタイムアタックにしたゲーム。
2つの値札を見て、量あたりで安いほうをタップする。

- HTML5 / CSS3 / Vanilla JavaScript（ライブラリ・バックエンドなし）
- 自己ベスト（合計タイム）を `localStorage` に保存。それ以外は何も送信しない
- ホスティング：Cloudflare Workers（静的配信）

## 遊び方

- 10問。量あたり（100gあたり・1個あたり など）で安いほうをタップ
- 間違えると +5秒（`PENALTY`）。答え合わせ（単価の表示）の間はタイマーを止める
- PC は ← → キー（または 1 / 2）で選べる。Enter でスタート

## 問題の作り方（`script.js` の `makeQuestion`）

- 商品カタログ（`ITEMS`）から1つ選ぶ。豚こま・鶏むね・牛切り落とし・合いびき・鮭・たまご・牛乳・緑茶・お米・トイレットペーパー・納豆
- 2つの量を選び、片方の単価を少し高く（または安く）して値段を作る。値段は末尾が 8 か 0 のスーパーらしい数字に寄せる
- 量が多いほうが値段も高い組み合わせだけを出す（見ただけでわかる問題にしない）
- 表示上の単価（小数1桁）が同じになるものは出さない

| 問題 | 単価の差 | そのほか |
|---|---|---|
| 1〜3問目 | 10〜20% | 肉（g）だけ |
| 4〜6問目 | 5〜10% | 全商品 |
| 7〜10問目 | 2〜5% | kg と g、L と ml が混ざる組み合わせを優先 |

## 称号

タイム（ミスの加算込み）とミスの数の両方を満たしたもの。適当に速く押すだけでは上位にならない。

| タイム | ミス | 称号 |
|---|---|---|
| 25秒以内 | 1回以内 | 特売ハンター |
| 35秒以内 | 2回以内 | 家計の達人 |
| 50秒以内 | 3回以内 | 買い物上手 |
| 75秒以内 | 5回以内 | ふつうの買い物客 |
| それ以外 | | 値札を見ない人 |
