# 目分量 (Mebunryo)

定規を使わず、目分量だけで答える図形の感覚ゲーム。
12種類のお題からランダムに10問出題し、正解とのズレを1問100点（合計1000点満点）で採点する。

- HTML5 / CSS3 / Vanilla JavaScript（ライブラリ・バックエンドなし）
- 自己ベスト（合計点の最大）を `localStorage` に保存。それ以外は何も送信しない
- ホスティング：Cloudflare Workers（静的配信）

## お題（12種類）

| お題 | 操作 | ズレの測り方 | 0点になるズレ |
|---|---|---|---|
| まんなか | 線上をタップ | 線の長さに対する% | 10% |
| 分数の位置（1/3・3/4 など） | 線上をタップ | 線の長さに対する% | 12% |
| 円の中心 | タップ | 半径に対する% | 25% |
| 重心 | タップ | 辺の平均長に対する% | 25% |
| 角度（30°〜150°） | ドラッグで線を回す | 度 | 18° |
| 直角 | ドラッグで線を回す | 度 | 12° |
| 垂直（傾いた枠の錯視つき） | ドラッグで線を回す | 度 | 8° |
| 平行 | ドラッグで線を回す | 度 | 12° |
| 同じ長さ | ドラッグで線を伸ばす | 長さの比 | 20% |
| 正方形 | 上下ドラッグで高さ | 縦横比 | 18% |
| 面積の倍（2倍・3倍） | ドラッグで円の半径 | 面積比 | 45% |
| コップ半分 | 上下ドラッグで水位 | 体積%のズレ（円すい台で計算） | 20ポイント |

得点は `100 × (1 − ズレ ÷ 0点になるズレ)`（0未満は0）。許容幅は `script.js` の各お題の `judge()` で調整する。

## ローカルでの動作確認

```bash
python3 -m http.server 8080
```

`http://localhost:8080/mebunryo/` を開く。
