# サウナ診断 (Sauna Type)

12の質問に答えると、あなたの「サウナタイプ」を8種類から診断する診断ゲーム。
MBTI風に3文字のコード（例：`HDS`）が付き、結果はURLでシェアできる。

- HTML5 / CSS3 / Vanilla JavaScript（ライブラリ・バックエンドなし）
- 回答はどこにも送信・保存しない
- ホスティング：Cloudflare Workers（静的配信）
- **2026-09-15 から Ludom のトップには載せていない。`noindex` 付きで、URLを知っている人だけが開ける**（戻すときは `index.html` にカードを戻し、`noindex` を外す）

## 仕組み

3つの軸 × 各4問 = 12問。各軸の配点は `2,1,1,1` の合計5点で、必ず奇数になるため同点が出ない。

| 軸 | 左（コード） | 右（コード） |
|---|---|---|
| 温度 | 灼熱 `H` | マイルド `M` |
| 水風呂 | ダイブ `D` | 慎重 `A` |
| スタイル | ソロ `S` | グループ `G` |

## 8タイプ

| コード | タイプ |
|---|---|
| HDS | 🧘 サ道の求道者 |
| HDG | 🔥 熱波師 |
| HAS | 🐢 サウナ室のヌシ |
| HAG | 📣 熱弁サウナー |
| MDS | 🧊 水風呂の哲学者 |
| MDG | 🚌 サウナ遠足隊長 |
| MAS | 🍃 外気浴の仙人 |
| MAG | 🍺 サ飯の座長 |

## シェア

結果画面のURLは `sauna-type/#HDS` のようにコードがハッシュに入る。
このURLを開くと、診断せずにそのタイプの結果ページが直接表示される。

## 設問・タイプ文言の編集

`script.js` 冒頭の `QUESTIONS` と `TYPES` を編集する。
設問を増減する場合は、各軸の合計配点が奇数になるように `weight` を調整すること。

## ローカルでの動作確認

```bash
python3 -m http.server 8080
```

`http://localhost:8080/sauna-type/` を開く。
